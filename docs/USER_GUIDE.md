# SiteCam 工程现场使用指南

SiteCam（工程水印相机）面向施工记录、现场巡检和工程留档。工程资料默认留在手机本地，无需注册账号。下面用虚构的“滨江路雨污分流改造”工程说明常用操作。

本版：`0.4.3` · Android 使用指南

官方下载：https://yuriaqua.com/sitecam/ 。鸿蒙开发版的安装、独立相册副本和兼容性边界请查看仓库 harmonyos/README.md；本指南的系统相册文件共享规则仅适用于安卓版。

系统要求：Android 8.0（API 26）及以上

## 安装与权限

1. 从项目官网的下载页获取 APK，安装后打开 SiteCam。
2. 完成或跳过首次功能指引后进入权限指引，点“开启所需权限”，集中申请当前尚未授权的相机、定位和麦克风权限。
3. 定位和录音是可选的，可以暂时跳过；相机未授权时不能拍摄。已经授予的权限不会重复申请。
4. 以后缺少权限时，从相机页出现的提示按需补开；定位拒绝后仍可拍照、录像和导出，录音拒绝后仍可录制无声视频。

## 首次功能指引

1. 新装或首次使用会看到 4 页指引：先选工程、选择横竖方向、按日期找资料和导出锁定。
2. 点“跳过”或最后一页的“开始使用”后，以后启动和正常升级都不会自动显示。
3. 中途退出且没有跳过，下一次打开会继续显示；指引状态会在手机本地保存。
4. 指引完成或跳过后进入权限指引，点“开启所需权限”，集中申请尚未授权的相机、定位和麦克风；定位和录音可暂时跳过，完成授权或点击暂时跳过后，之后不再自动弹出，已有全授予会直接跳过。
5. 以后缺少权限时，从相机页的提示按需补开；进入“设置 → 使用指南 → 重新查看功能指引”可以随时重看，且不会清空已完成状态。

## 工程与线路

1. 在相机页点顶部当前工程名称打开快捷选择面板；点“全部工程包”进入工程管理，或点“新建工程”直接创建并切换。填写工程名称，类别、地点和备注按需要填写。
2. 每个工程建一个工程包，线路名称可按需要填写。例如工程填写“滨江路雨污分流改造”，线路填写“北段雨水管”。
3. 点工程卡片查看该工程的资料和媒体，不会切换当前拍摄工程。卡片上的“去拍摄”会切换当前工程并返回相机；“编辑”和“导出”直接处理该工程，也可从更多中归档。
4. 长按或进入批量操作，可批量分类、归档、锁定、解锁、删除或导出工程。删除前先导出需要留档的资料。
5. 搜索工程或线路名称即可定位资料；锁定当前工程只会停用该工程的新拍照和录像，不会自动切换工程，编辑、移动、删除和导出仍可使用。

## 拍照、录像与水印

1. 先选工程和线路，再在取景页点击快门拍照；切换到录像后点一次开始、再点一次结束。当前工程会记录照片和视频数量。
2. 闪光灯短按在自动、开启、关闭之间切换；长按闪光灯图标可开关常亮手电。
3. 点取景页顶部独立的拍摄方向图标，在弹出的菜单中选择自动、竖屏、左横屏或右横屏。应用会记住你的选择，画面和成片保持同一方向。
4. 允许定位后，水印可显示地点；在工程编辑页维护工程名称、线路、类别、地点和备注，在设置中选择要显示的水印字段与自定义字段。拍摄时间由记录自动写入，字段较多时会自动排版。水印样式可在“设置 → 水印样式与字段”或取景页直接点水印卡片后更换。
5. 抓拍模式默认开启，在“设置 → 拍摄与保存”调整开关与抓拍快门；优先保证工程文字、铭牌和施工部位可识别，自动对焦与曝光随现场光线调整。
6. 点闪光灯旁的连拍按钮开启连拍，再点快门开始、再次点快门停止；停止后会保存已经拍到的照片。连拍始终使用抓拍设定，不受设置中抓拍开关影响。
7. 普通拍摄与编辑提供四档画质：更小文件、标准省空间、较清晰、原尺寸高清；抓拍和连拍采用兼顾文字细节与速度的尺寸和压缩设置。
8. 快速水印编辑顶部的“工程名称”可直接定位输入框，修改水印内容后即时预览。
9. 天气字段可以编辑并写入水印；安卓在系统允许访问且位置、时效匹配时读取系统天气。

## 更换水印样式

1. 在设置打开“水印样式与字段”，或在取景页点水印卡片进入快速修改，切到“外观”并点当前样式。
2. 面板提供八款样式：经典工程水印、极简水印、工程信息板、蓝白工程记录、施工表格、巡检记录、验收记录、大字时间地点。
3. 点卡片查看大预览，先比较版式和信息位置；原有字段、字号和不透明度会保留。
4. 确定后点“使用此样式”才保存，点“取消”会回到原来的样式。

## 相册、搜索与日期

1. 点相机页缩略图进入当前工程相册。工程卡片显示照片、视频和问题数量。工程会自动记录首拍日期和末拍日期；还没有拍摄时显示“尚未拍摄”。
2. 在工程管理中搜索工程或线路，并按最近拍摄、创建时间、编辑时间、工程名或线路首字母升序/降序排列。
3. 在相册中用年月日区间筛选照片，例如只看 2026 年 9 月 1 日到 9 月 3 日的夜间施工记录。
4. 多选照片或视频后，可移动、分享、导出或删除；操作前确认当前工程范围，避免把资料放错线路。
5. 相册可查看全部工程或指定工程。拍摄前回到相机页，确认左上角的工程名称。

## 记录和跟进问题

1. 拍摄时点“记问题”，再拍下需要跟进的位置；也可以在照片或视频详情里点“标记问题”。
2. 填写问题名称和说明，选择“一般、重要、严重”级别，再保存。
3. 打开已有问题的照片或视频，点“编辑问题”，选择“待处理”“处理中”或“已完成”后保存。
4. 问题会关联照片或视频，导出工程包时会随清单和报告一起带走。

## 查看、编辑与标注

1. 打开详情后可在 1 到 8 倍之间缩放；双击放大或还原，双指拖动查看画面细节。
2. 编辑时可水平翻转、垂直翻转、旋转 90 度或自由裁剪，也可以撤销和重做。
3. 现场标注支持箭头、文字和马赛克，适合指出管线、裂缝或需要整改的位置。
4. 详情页可以切换原图和独立成品。保存成品不会覆盖原图，水印会跟着整张图的方向和裁剪一起变换。
5. 分享或导出前检查成品是否包含需要的标注和水印，原图仍可留作复核。

## 导出工程资料

1. 在工程管理或相册中选择一个工程、多个工程或选中的照片或视频，点击“导出”。
2. 可导出为一个 ZIP，或保存到一个总文件夹。批量选择多个工程时，会合并为一个 ZIP 或总文件夹，其中每个工程有独立目录；需要每个工程各一个 ZIP 时，分别导出即可。
3. 每个工程目录包含照片、视频、编辑成品、工程信息、照片和视频清单及报告；文件名会保留工程和日期线索。
4. 导出时可保持原文件（默认），也可生成压缩副本。压缩副本不会替换手机里保存的原文件。
5. 完工确认后锁定工程，减少误拍；锁定后仍可补充备注、移动、删除和导出既有资料。

## 保存位置与换机

1. 保存到系统相册默认关闭；新照片、视频和编辑成品默认保存在 SiteCam 内，打开设置后也可保存到系统相册供其他应用使用。
2. 两处使用同一份文件，打开系统相册保存不会自动搬走旧资料；以后切换开关也不会搬移过去的文件。
3. 在系统相册里删除共享文件时，SiteCam 里对应文件也会受影响。删除前先确认是否已有导出副本。
4. 换机或卸载前先导出各工程的 ZIP 或总文件夹，再把资料保存到新手机查看；当前版本不提供把工程恢复成可继续拍摄工程的功能。

## 隐私与常见处理

1. SiteCam 无广告、无账号和自动上传；工程、照片、视频、地点水印和问题记录默认只在本机使用。
2. 地点没有显示时，检查系统定位开关和应用权限；已授权但没有有效自动地址时，可点刷新入口重试。取得有效地址后入口会收起；仍不可用时，可在工程地点手动填写地址并继续拍摄。
3. 录像没有声音时，重新开启麦克风权限后再开始下一段录像；已经拍好的无声视频不会自动补录声音。
4. 字段太多时，到“设置 → 水印样式与字段”减少字段或调整字号，再拍摄新的记录。
5. 提交反馈前遮住工程名称、地址、地点、时间、人员和车辆信息，不要公开真实工程资料或签名文件。

## 获取帮助

1. 在设置中打开“使用指南”，没有网络也能阅读本指南。
2. 反馈问题时写明手机型号、Android 版本、所在页面、操作步骤和预期结果。
3. 需要复现问题时使用虚构工程和脱敏截图，保留导出的报告以便核对。

## 更换桌面图标

1. 打开“设置 → 桌面图标”，先查看当前选中的图标样式。
2. 新装默认使用 D「工程现场」；也可选择 A「蓝图镜头」、B「工程印记」或 C「现场坐标」，选择会立即生效，返回桌面查看。
3. 切换只影响桌面入口，工程资料、拍摄记录和应用内页面不受影响。
4. 重启或正常升级后会保留你的选择；如果桌面暂未刷新，稍等片刻或重新打开桌面。

## 修改水印标签、顺序与内容

- 在“设置 → 水印样式与字段”修改字段标签、调整顺序；所有样式都遵循这里的顺序。
- 新增字段时先填写标签，再在“水印编辑”的“内容”页填写或修改内容；设置中的水印编辑和相机页点水印打开的编辑面板都可使用。空内容的自定义字段暂不显示在成片上。
- “水印编辑 → 字段”页的“恢复默认”只恢复系统字段的标签与顺序；自定义字段按原有相对顺序排在系统字段后，已有内容、字段开关和样式保持不变。
- 修改标签或排序不会改变已填写的内容。新设置用于之后的照片和视频，历史照片保持原样。

## 系统相册删除与恢复

系统相册删除或移入回收站后，返回应用会同步隐藏失效媒体，并更新缩略图和工程数量。系统回收站恢复后会重新显示；工程关联记录保留。权限或存储暂时不可用不会直接清除记录。此规则仅针对 Android 共用系统相册文件，鸿蒙的独立副本规则不变。


## 屏幕适配与安装版本

日常自用推荐 Release，官网默认下载 Release。Debug 用于调试，独立包名可共存，工程和资料不会自动在两版之间共享。旧版 Release 可直接覆盖升级，请勿为更新卸载应用。

普通长条手机竖屏快门在底部操作区居中，下方留有握持空间；横屏快门位于右侧操作区。平板与折叠屏按各自可用窗口排布控件。大屏、阔折叠内外屏和平板空间足够时，相册左侧列表、右侧预览，收起后继续查看同一照片。小折叠外屏保留拍摄所需操作，复杂操作可展开手机继续。

## 刷新地址

取景页在已经授予定位权限但没有有效自动地址时，会在有空间的取景角落显示“刷新地址”。按钮会优先使用新鲜坐标重新反解；没有可用坐标时才请求一次定位。定位未开启、定位暂不可用和地址服务失败会分别提示，状态结束后可以再次重试。水印、快门和系统安全区附近没有可用位置时，刷新入口会放到相机操作区；小折叠外屏也可从操作区刷新地址。

## 海拔与冻结记录

在“设置 → 水印样式与字段”打开“海拔”后，海拔显示在位置字段下方。有效的 0 米和负值会原样记录；没有新鲜海拔时显示“不可用”，不会用 0 代替。照片、视频预览和最终成片使用同一份拍摄时冻结的位置与海拔数据，已有照片和旧模板不会因升级自动增加海拔或改写开关。

## 快捷切换工程

取景页顶部一直显示当前工程名称，点名称打开快捷选择面板。普通手机竖屏从底部打开面板，横屏和大屏使用适合宽度的选择面板；Android 面板将“全部工程包”和“新建工程”固定在列表上方；当前工程单独显示，“最近拍摄”按工程内已保存照片或录像的最近拍摄时间倒序排列（不含当前工程、已归档工程和没有拍摄记录的工程，包括已锁定的工程）。切换或编辑工程不改变拍摄排序。“全部工程包”可以查看并选择已归档或锁定的工程，但它们仍会保留禁止拍摄状态；回到相机后可点“恢复工程”或“解锁拍摄”。拍摄、录像和保存期间切换按钮与快门都会暂时停用，切换成功后自动回到相机。

## 镜头、倍率与双指缩放

取景页的快捷倍率对应设备可调用的原生镜头，数量与倍率随设备变化。双指可连续调整缩放；支持切换的镜头会随倍率衔接，两个原生倍率之间也可继续调节。

长按切换镜头按钮可以打开镜头选择。录像期间按当前拍摄能力限制切换，停止录像后可重新选择。

## 相机控件外观

在“设置 → 相机控件外观”选择普通或透明。透明外观降低覆盖取景画面的控件底板不透明度，文字与图标保持可见；照片、视频和水印外观不受影响。

## 阅读指南

章节目录和正文分别滚动，进入章节会回到开头。窄屏可点章节顶部的“返回目录”，或使用系统返回；宽屏可直接在左侧目录切换章节。
