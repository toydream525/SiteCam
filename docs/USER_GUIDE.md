# SiteCam 使用指南

SiteCam（工程水印相机）是一款面向施工记录、现场巡检和工程留档的 Android 应用。它免费、开源、无广告，核心功能无需注册账号，项目、照片索引和问题记录默认保存在本机。

当前正式版：`0.2.7`  
系统要求：Android 8.0（API 26）及以上

## 1. 安装与首次启动

1. 下载正式版 APK，并在系统提示时允许当前下载工具安装未知来源应用。
2. 安装后打开 SiteCam。
3. 首次启动只需授予相机权限即可拍照。
4. 定位权限是可选的。允许后，水印可以显示拍摄地点和 GPS 坐标；拒绝后仍可正常拍照、录像和管理项目。
5. 首次录像时，系统会申请麦克风权限。拒绝后仍可录制无声视频。

> 建议只从项目官网或 GitHub Releases 下载 APK。覆盖升级必须使用相同签名；如果系统提示签名不一致，请先确认安装包来源，不要直接卸载，以免丢失本地项目数据。

## 2. 创建和切换工程项目

1. 点击相机页左上角的工程名称，进入“工程项目管理”。
2. 点击右下角“+”新建工程。
3. 填写工程名称；工程类型、地点和备注可按需填写。
4. 点击工程卡片即可切换当前工程，黄色边框和勾选标记表示当前选中项目。

之后拍摄的照片、视频、问题记录和标注成品都会归入当前工程，避免不同项目的资料混在一起。

## 3. 拍照与录像

- 点击取景画面进行对焦。
- 点击或双指缩放取景画面，也可以直接选择设备支持的焦距档位。
- 点击“拍照 / 录像”切换拍摄模式。
- 点击快门拍照；录像模式下点击一次开始，再点击一次结束。
- 点击右下角翻转按钮切换前后摄像头。
- 点击左下角缩略图进入当前工程相册。
- 竖屏和两种横屏握持方向都会同步调整取景与成片方向。

### 闪光灯与常亮手电筒

- 短按闪光灯图标：在自动、开启和关闭模式之间切换。
- 长按同一个闪光灯图标：开启或关闭常亮手电筒。

## 4. 水印设置

点击右上角齿轮进入“设置与设备诊断”。

可以调整：

- 默认水印样式：经典工程水印、极简水印、工程信息板。
- 水印字段：开启、关闭、新增、编辑和排序字段。
- 自定义内容：例如标段、施工单位、监理单位。
- 字号缩放、水印位置和背景透明度。
- 照片保存质量。

取景页水印和最终照片使用同一套排版规则。长地址、不同字号和横竖屏会自动重新排版，避免字段互相覆盖。

## 5. 标记现场问题

1. 在相机页点击红色警示三角，开启“重点问题”模式。
2. 拍摄照片或视频。
3. 在弹出的窗口填写问题名称。
4. 选择“一般、重要、严重”级别。
5. 可补充问题原因、整改要求或备注，然后保存。

问题媒体会显示警示标记，并可在工程相册中通过“问题照片”快速筛选。选择“取消标记”时，媒体仍会作为普通现场记录保存。

## 6. 相册与现场标注

进入工程相册后，可以按“全部、今天、问题照片”筛选。

打开照片详情页后可以：

- 查看拍摄时间、地点、分辨率和文件信息。
- 分享照片或视频。
- 打开现场标注工具。
- 删除单个媒体文件。

现场标注支持箭头、矩形、圆圈、画笔、文字和马赛克。保存后会生成独立标注成品，原图仍然保留。

## 7. 导出工程资料

在“工程项目管理”中点击“导出工程包”，可以选择两种方式：

### 压缩包

适合普通 Android 手机和即时分享。应用会生成 ZIP，并调用系统分享面板发送或保存。

### 不压缩文件夹

适合部分华为 Android 或鸿蒙设备，也适合不方便打开 ZIP 的文件管理器。选择系统允许写入的目标文件夹后，应用会直接导出：

```text
工程名称/
├── project_info.json
├── photo_index.csv
├── export_report.json
├── Photos/
├── Videos/
└── Annotations/
```

如果华为文件管理器无法打开应用默认输出目录，请优先使用“不压缩文件夹”，并在系统目录选择器中选择“下载”或你自己创建的工程资料目录。

## 8. 数据与隐私

- SiteCam 无广告、无账号系统、无行为跟踪 SDK。
- 工程资料、问题记录和设置默认保存在设备本地。
- GPS 仅在用户授权且使用相机时读取。
- 应用不会自动上传照片、位置或工程信息。
- 卸载应用可能清除数据库和应用专属目录中的数据，卸载前请先导出重要工程。

## 9. 常见问题

### 水印没有显示地点或 GPS

检查系统定位开关和 SiteCam 的位置权限。刚进入室内或信号较弱时，定位需要一定时间；未定位不影响拍摄。

### 录像没有声音

在系统设置中为 SiteCam 开启麦克风权限，再重新开始录像。

### 华为手机无法找到导出文件

进入工程管理，选择“导出工程包 → 不压缩文件夹”，再通过系统目录选择器指定“下载”目录。不要依赖文件管理器直接进入应用私有目录。

### 鸿蒙文件管理器无法解压 ZIP

改用“不压缩文件夹”导出，照片、视频、标注成品和 CSV/JSON 清单会直接写入所选目录。

### 字号缩放后水印字段减少

新版会根据可用空间自动缩放和折行。请在“设置 → 自定义水印字段与样式”中调整字号，并确认需要的字段已开启。

### 横屏翻转后画面方向错误

请确认安装的是最新正式版。SiteCam 会分别处理摄像头位于左侧和右侧的两种横屏方向。
