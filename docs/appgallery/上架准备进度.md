## 2026-09-22 权限驳回项修复（审核证据：应用内提示去系统设置，但系统设置无权限开关）

华为提供的截图证据：权限页三项均显示「未开启 · 需前往系统设置」、主按钮为「去系统设置开启」，而系统设置的应用详情页只有「通知 / 应用联网」，没有任何权限开关。根因是应用从未调用 `requestPermissionsFromUser`，系统便不会注册权限节点。本轮修复（版本号仍为 `0.3.2 (15)`）：

1. **权限请求闭环**：新增持久化 `systemPermissionsRequested`。未请求过时权限页主按钮显示「开启所需权限」而非「去系统设置开启」；系统设置跳转收敛为唯一 `openAppSettings()` 并在跳转前确保至少请求过一次。
2. **权限入口补回**：设置页新增「权限设置」入口（原入口位于死代码 `settingsPage()`，实际不可达）；权限页返回键与系统返回统一。
3. **权限卡片排版**：标题与状态行改为左对齐（此前因 ArkUI `Column` 默认居中而与描述文字错位）。
4. **权限页/指引页显示不全**：权限页主按钮与底部说明原本位于滚动区内部且滚动条被关闭，手机竖屏与平板大字号下会被截断。已改为「固定页头 + 可滚动说明区 + 固定在底部的操作区」，并按可用高度 `< 560vp` 进入紧凑模式；首次指引页同时补上滚动与限宽，覆盖手机/平板/折叠屏/小折叠内屏/阔屏。
5. **定位与海拔**：手动刷新真正重新请求硬件定位并拒绝缓存解；修正并发覆盖、硬件失败被误报成功、逆地理尝试耗尽误判失败三处缺陷；海拔不可用（0 且无垂直精度）时继承上一版真实读数。
6. **快门声**：替换为 CC0 真实单反快门录音（`harmonyos/scripts/prepare_shutter_sound.py`，来源与许可见 `THIRD_PARTY_NOTICES.md`）。
7. **验证**：卸载重装构造「从未申请过权限」状态后，主按钮显示「开启所需权限」、卡片显示「未开启」，点击后系统依次弹出 3 个权限弹窗，授权后即时刷新并持久化 `systemPermissionsRequested`（截图见 `harmonyos/verification/appgallery-3.1-evidence/`）；真机运行时套件 **54/54 通过**，见 `harmonyos/verification/device-results-0.3.2-tablet.json`。
8. **产物**：`SiteCam-0.3.2-HarmonyOS-AppGallery-Signed.hap/.app`（SHA-256 `8ad8676d…83d1`），已同步到桌面用于上传。
9. **完整记录**：`harmonyos/verification/REVIEW-0.3.2-权限与海拔.md`。
