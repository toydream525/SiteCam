# SiteCam工程水印相机 · 商店文案

## 一句话简介（17字以内）

工程人自己做，自己用，免费无广告

## 应用介绍

工程人自己做的工程水印相机。

从施工记录、现场检查到资料交接，SiteCam把拍摄、水印、照片标注和工程管理放在一起。现场拍得清楚，回头找得到，交资料也有条理。

【拍照录像，现场信息一起留存】
支持拍照与录像，为现场记录添加工程名称、时间、位置和自定义水印。水印样式、字号和透明度可按需要调整，让不同工地、不同用途的记录都有合适的呈现。

【按工程和线路整理，照片各有归属】
按工程、线路管理照片与视频，切换工程后继续拍摄。回看时按日期查找，把不同项目、不同阶段的资料分清楚，减少在相册里反复翻找。

【裁剪与标注，把重点说明白】
支持照片裁剪、旋转，以及箭头、圈画和文字标注。需要关注的位置直接标出来，让现场情况和沟通重点更直观。

【记录问题，也跟进处理进度】
为现场问题补充说明、标记等级并更新处理状态。从发现问题到复查处理，结合照片保留记录，方便后续检查与交接。

【工程资料整包导出，归档交接更方便】
将工程照片、视频和资料清单整理导出，用于汇总、备份和交付。完工后可锁定工程，避免继续拍入新资料，让已整理好的记录保持清晰。

【多种屏幕形态，兼顾现场操作】
适配普通直屏、阔直屏、折叠屏和平板，兼顾横竖屏下的拍摄、浏览与资料整理。具体体验以设备和系统版本为准。

无需注册或登录，内置使用指引，常用操作随时可查。从开工记录到完工交接，把现场资料留清楚、管明白。

## 版本更新说明（v0.3.5）

鸿蒙版统一支持自动获取地点地址，地址不可用时可手动填写；完善坐标与海拔信息记录。

## 审核备注

本应用无需注册或登录。首次启动完成使用引导后，新建演示工程及线路即可拍摄。相机用于拍摄，麦克风用于录像收音，定位用于现场位置水印。应用通过 HarmonyOS 系统地址服务获取地点文字，系统服务可能使用网络；应用未声明 INTERNET 权限，地址不可用时用户可手动填写工程地点。工程相册可查看照片、标注问题并导出工程资料。请使用虚构工程信息进行测试。
