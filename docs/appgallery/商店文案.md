# SiteCam工程水印相机 · 商店文案

## 一句话简介（17字以内）

工程人自己做，更懂现场记录

## 应用介绍

工程人自己做的工程水印相机。

跑现场，最怕照片混在一起；交资料，最怕翻半天还找不到。SiteCam把拍摄、标注、问题跟进和工程整理放在一起，让每张现场照片都有清楚的归属。

【拍下现场，也记清来龙去脉】
照片带上工程、时间、位置与自定义水印。按现场需要调整水印样式、字号和透明度，让记录看得明白。位置记录需授权定位，并以实际定位结果为准。

【工程再多，照片也分得清】
按工程和线路整理资料，切换工程继续拍；回看时按日期查找，少在杂乱相册里来回翻。

【问题在哪，直接标给人看】
用箭头、圈画和文字标注现场问题，记录问题等级与处理状态。回头检查时，顺着照片看处理进度。

【交资料，按工程整包带走】
整理好的工程资料支持整包导出，方便汇总、备份与交接。完工后可锁定工程，避免继续拍入新资料。

【鸿蒙多种屏幕形态，现场用得顺手】
面向普通直屏、阔直屏、折叠屏和平板提供布局适配，兼顾横竖屏使用，让不同屏幕上的拍摄与资料整理更顺手。具体体验以设备和系统版本为准。

从第一张照片开始，把下一个工程的资料整理清楚。

## 审核备注

本应用无需注册或登录。首次启动完成使用引导后，新建演示工程及线路即可拍摄。相机用于拍摄，麦克风用于录像收音，定位用于现场位置水印。工程相册可查看照片、标注问题并导出工程资料。请使用虚构工程信息进行测试。
