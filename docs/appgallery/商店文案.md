# SiteCam工程水印相机 · 商店文案

## 一句话简介（17字以内）

工程人自己做，自己用，免费无广告

## 应用介绍

工程人自己做的工程水印相机。

从施工记录、现场检查到资料交接，SiteCam把拍摄、水印、照片标注和工程管理放在一起。现场拍得清楚，回头找得到，交资料也有条理。

【拍照录像，现场信息一起留存】
支持拍照与录像，为现场记录添加工程名称、时间、位置和自定义水印。水印样式、字号和透明度可按需要调整，让不同工地、不同用途的记录都有合适的呈现。

【按工程和线路整理，照片各有归属】
按工程、线路管理照片与视频，切换工程后继续拍摄。回看时按日期查找，把不同项目、不同阶段的资料分清楚，减少在相册里反复翻找。

【裁剪与标注，把重点说明白】
支持照片裁剪、旋转，以及箭头、圈画和文字标注。需要关注的位置直接标出来，让现场情况和沟通重点更直观。

【记录问题，也跟进处理进度】
为现场问题补充说明、标记等级并更新处理状态。从发现问题到复查处理，结合照片保留记录，方便后续检查与交接。

【工程资料整包导出，归档交接更方便】
将工程照片、视频和资料清单整理导出，用于汇总、备份和交付。完工后可锁定工程，避免继续拍入新资料，让已整理好的记录保持清晰。

【多种屏幕形态，兼顾现场操作】
适配普通直屏、阔直屏、折叠屏和平板，兼顾横竖屏下的拍摄、浏览与资料整理。具体体验以设备和系统版本为准。

无需注册或登录，内置使用指引，常用操作随时可查。从开工记录到完工交接，把现场资料留清楚、管明白。

## 版本更新说明（v0.4.2）

v0.4.0 以来的更新：

- 全形态设备适配：优化折叠屏与平板体验，横竖屏拍摄均增加防误触握持留白。
- 页面切换平稳：进出二级页面取景画面不再跳动，水印与文字完整显示不截断。
- 变焦更稳定：支持多焦段顺滑切换，切换后保持所选倍率。
- 离线位置记录：断网保留卫星坐标并支持手填地点，联网自动解析地址。
- 水印自适应排版：文字过多时紧凑排列，不挡核心取景。
- 全新视觉：新增四款桌面图标（设置中可换），使用指引升级为清晰大字图解。
- 资料整理优化：工程与相册排版更清晰，整包导出更便捷。
- 水印宽度可调：水印编辑的“外观”和拍摄页的“水印”面板都能直接调水印宽度，长内容自动换行，字号不变。
- 开场指引更好用：折叠内屏等大窗口下改为左图右操作，平板竖屏和手机居中铺满。
- 显示更清晰：浅色模式下强调文字更清楚，底部按钮避开系统导航条。
- 操作更顺：滚动到边界有回弹，页面切换更平缓。
- 支持导入已有照片，添加水印后另存新照片；照片上已有的水印暂不支持修改或替换。
- 文字标注支持拖动和再次编辑，用于添加现场备注；文字输入仅在选中文字工具时显示。
- 修复视频回放画面被裁切的问题，视频预览与回放等比完整显示。
- 修复部分旧照片标注记录异常时再次编辑可能丢失原有标注的问题。
- 提升功能指引插图清晰度，优化手机外形与画面细节。

## 审核备注

本应用无需注册或登录。首次启动完成使用引导后，新建（或选择）工程即可拍摄。相机用于拍摄，麦克风用于录像收音，定位用于现场位置水印；三者均可按需授权，拒绝定位或录音仍可拍照和导出。

水印宽度在「水印编辑 → 外观」和拍摄页的「水印」面板中调整，范围 30%–90%，默认 60%；水印样式、字段在设置与水印编辑中查看。

应用通过 HarmonyOS 系统地址服务获取地点文字，系统服务可能使用网络；应用未声明 INTERNET 权限。地址不可用时可在工程中手动填写地点。

照片和视频保存在应用内，可导出工程资料包；鸿蒙版「另存到系统相册」保存独立副本。请使用虚构工程信息进行测试。
