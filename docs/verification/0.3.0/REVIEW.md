# Android 0.3.0（13）审核记录

## 已修复

- 统一手机、宽屏和折叠屏判定；方屏右侧快门，小外屏使用简化控制。
- 横屏在布局中预留右侧 58–68dp 握持空间；竖屏保留原有抬高快门与底部握持空间。
- 修复用户反馈的变焦档位被取景画面裁切：控制组上移距离按实际剩余高度限制，竖屏操作区至少预留 196dp，快门位置保持原方案。
- 大屏相册分栏复用原有预览；折叠、旋转保留照片选择、成品切换和编辑状态。避免窗口调整重复绑定镜头而重置变焦。

## 验证结果

- 完整核心单元测试 103 项通过；后续几何与方向定向复测通过。
- 最终 Debug、Release、测试 APK 构建及 Release lint 通过，最终日志为 sitecam-android-030-overlap-final-build.log。
- 4 项实际控件布局测试通过，覆盖小外屏模拟尺寸、横屏握持空间、普通及紧凑竖屏变焦边界；详见 controls.txt。
- API 37 折叠模拟器完成拍照、标注保存及相册分栏；连续两轮合拢展开，同一照片和编辑成品选择保留，详见 fold-state.txt。
- 小米 14 / Android API 36：Debug 安装成功；Release 从 0.2.10 覆盖到 0.3.0 成功，旧工程选择保留。变焦档位完整显示，原快门位置与底部空间保留。
