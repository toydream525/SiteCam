# Android 0.2.10 三轮审查

本次修复水印标签与字段排序，并在水印管理栏增加“恢复默认”。正式包版本为 0.2.10（12）。

## 第一轮：字段数据与兼容

- Debug、Release 各 99 项单元测试通过；Release 构建和 lint 通过。
- 验证“工程名称”改为“今日水印”、系统字段与自定义字段混合排序、空内容与禁用字段过滤、长标签完整显示。
- 验证标签、排序的修改不会覆盖新填写的内容；水印快照可保存新标签与顺序，旧快照保持历史显示。
- “恢复默认”只改当前模板的系统标签和字段顺序；内容、自定义字段、字段开关、样式及其他模板保持不变，重复恢复结果一致。

## 第二轮：界面与统一渲染

- 小米手机原生平台测试通过：设置页新增、编辑弹窗均只有标签输入；改名与排序落库，已有内容保留。
- 八款样式均验证首行自定义字段与改名后的系统标签；照片和视频水印像素一致。
- 逐一检查八款真机字体渲染图，确认蓝白工程记录的行背景不会覆盖前面的字段。
- 正式版实机确认“恢复默认”位于水印字段管理栏，与“新增字段”并列。

## 第三轮：升级与实际成片

- 小米 23127PN0CC 从 0.2.9 原位升级到正式版 0.2.10（12）成功；原有工程、记录及字段设置保留。
- 实拍一张照片及一段约 26 秒视频，核对保存成片中的修改标签和字段顺序；视频可解码，保留 H.264 画面和 AAC 音轨。
- 临时测试应用已移除，手机保留正式版。

实拍内容仅用于本地检查，不随代码或发布页面上传。
