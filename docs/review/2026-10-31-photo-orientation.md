# 鸿蒙拍摄照片方向修复

日期：2026-10-31。版本：0.4.4（24）。

用户反馈：照片底图上下倒置，水印保持正向；强制横屏时仍须与预览一致。

## 原因与修复

拍摄通过相机 API 指定照片方向，返回的 JPEG 可以将方向保存在 EXIF 中。拍摄烧制路径直接解码像素，未应用 EXIF 方向，随后叠加水印并将成片按正常方向保存；底图因此可能未转正，水印却始终正向。导入照片路径原本已有方向归一化。

拍摄路径现在读取并应用 JPEG 的 EXIF 方向，再按预览镜像、裁切、缩放、叠加水印；与导入路径共用方向变换函数。没有添加固定 180° 补偿，没有改变屏幕方向菜单或握持布局。相机请求和图像处理日志补充方向数值，便于对照实际拍摄。

## 原生回归

在连接的 MLR-AL10 上运行测试模块，使用不对称四色 JPEG、8 种 EXIF 方向和镜像开关，经过生产 `MediaService.capture` 的任务池及烧制路径，检查输出尺寸、场景四区颜色和水印像素位置。

| 阶段 | 通过数 | 结果 |
| --- | ---: | --- |
| 修复前 | 2 / 16 | 普通方向的两组通过，其余方向出现底图朝向或最终尺寸错误。 |
| 修复后 | 16 / 16 | 8 种方向及镜像组合全部通过，底图转正且水印不随底图再次旋转。 |

证据位于 `dist/fixes/2026-10-31-photo-orientation/`：`before-native.json`、`after-native.json`、方向 3 修复前后样图、原生构建日志。

主应用已使用既有 Debug 身份覆盖安装。临时测试模块已移除，主应用模块和资料保留。实际相机四种方向下的预览与成片对照仍在进行，以真机观察记录为准。
