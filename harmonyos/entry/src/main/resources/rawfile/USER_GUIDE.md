# SiteCam 工程水印相机 · HarmonyOS 原生版 v0.3.1

本指南对应 HarmonyOS 原生版 v0.3.1，适用于 HarmonyOS 5 及以上；相机、定位和视频能力以设备支持情况为准。工程、照片、视频和问题记录默认保存在本机，不需要账号或网络。

## 安装与权限

取得适用于本机的鸿蒙安装包后，按系统提示完成安装；具体分发状态以当前核实渠道为准。Android APK 不适用于本原生包。

首次打开会进入功能指引和权限指引。相机权限用于拍照和录像；定位用于地点和海拔水印；麦克风用于录像声音。定位和麦克风可以暂时跳过，相机未授权时不能拍摄。以后缺少权限时，在相机页按提示补开。拒绝麦克风仍可录制无声视频。

## 工程与资料

在“工程包”中新建工程，填写名称、线路、类别、地址和备注。拍摄页点左上角工程名称打开工程快捷切换，选择要拍摄或查看的工程；需要整理工程时再进入工程包页。搜索名称或线路，按日期或名称排序；批量操作支持分类、归档、锁定和导出。

锁定只禁止该工程新拍照和录像，仍可切换到该工程查看、编辑、移动、删除和导出；需要继续拍摄时先解锁。

## 拍照、录像与水印

先选工程，再进入“拍摄”。快门时冻结时间、工程信息、定位和水印设置；后续修改不会改写旧照片或旧视频。照片和视频的预览、成品使用同一套水印排版。

允许定位后，水印可显示地点。内置“海拔”字段位于“现场位置”下方，默认关闭；打开后读取拍摄瞬间的有效定位海拔，正值、零值和负值都按米显示。未提供海拔或定位已过期时显示“暂不可用”，不会用默认 0 冒充测量值。已有照片和视频沿用当时冻结的快照，不会在后续升级中新增海拔。地址不可用时可点击“刷新地址”重试定位和地址解析，刷新期间仍可拍摄。

照片四档画质分别为长边 1280、1920、2560 和原尺寸，JPEG 质量 65、75、85 和 95。录像结束后处理水印；处理失败会保留原片并显示待处理状态，可在相册详情中重试。进入后台会结束录制或取消处理，不保证后台持续转码。

取景页可选择自动、竖屏、左横屏或右横屏方向，应用会记住选择。闪光灯短按在自动、开启、关闭之间切换；长按闪光灯图标可开关常亮手电。设备不支持闪光灯、镜头或录像时，相应控件会显示不可用。

## 水印与模板

从相机的水印入口或设置中的“自定义水印字段与样式”进入同一面板。八款样式按面板宽度显示一到四列。切换样式保留字段、字号、透明度和位置；“使用此样式”才会改变拍摄配置，“取消”保持原配置。

设置页可修改标签、增删字段及调整排序。“恢复默认”只恢复系统字段标签和默认顺序，保留已填写内容、自定义字段和开关。已有模板升级时只补入关闭的海拔字段，其他字段的文字和相对顺序保持不变。

## 相册、问题和编辑

相册可按工程、日期、类别、问题等级和处理状态筛选。勾选资料后可移动、分享、删除或导出。照片支持缩放查看；详情中可以填写问题名称、说明、等级和处理状态。

编辑支持旋转、水平或垂直翻转、裁剪、箭头、文字和马赛克。保存编辑成品不会覆盖工程原图，详情可切换查看原图和独立成品。

## 导出与系统相册

工程导出可选择 ZIP 或总文件夹。文件夹通过系统授权保存到下载目录。导出包含工程信息、照片、视频、独立编辑成品、CSV 清单和结果报告；缺失文件会列入报告，不会假报全部成功。

“拍摄后保存副本到系统相册”会请求系统授权；取消不影响应用内原件。系统相册副本与工程原件是独立文件，两处独立删除。已存在资料可在详情中另存副本。卸载或换机前请先导出资料。

## 设备与显示

普通手机使用单栏，窗口达到 600 vp 显示更多列，840 vp 起使用列表和详情双栏。平板、折叠屏和分屏按窗口空间调整；旋转、展开和收起后保留当前工程、筛选、多选和编辑草稿。大屏照片编辑在右侧显示工具，相机侧边水印面板可滚动。

当前版本为 v0.3.1 HarmonyOS 原生版，适用于 HarmonyOS 5 及以上。实际相机、定位、H.264 视频和悬停能力以设备支持情况为准；模拟器能力不足时不能代替真实成片验收。

## 使用帮助与隐私

教程在“设置 → 使用技巧与教程”中离线可读，也可以重看首次功能指引。定位不可用时检查系统开关和应用权限；地址不可用时点击“刷新地址”，服务会先尝试新鲜定位的地址解析；地址或海拔暂不可用不影响保存工程资料。设置中的“拍照快门声音”默认开启，可单独关闭，不影响录像声音。录像没有声音时，重新开启麦克风权限后再开始下一段录像，已经拍好的无声视频不会自动补录声音。

SiteCam 无广告、无账号和自动上传。提交反馈前遮住工程名称、地址、地点、时间、人员和车辆信息，不要公开真实工程资料或签名文件。
