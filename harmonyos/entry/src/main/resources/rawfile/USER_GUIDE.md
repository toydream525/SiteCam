SiteCam 工程水印相机 · 鸿蒙原生开发版 0.2.8

本包未签名，需要开发环境；不作为普通真机发行包。官方下载与说明：https://yuriaqua.com/sitecam/ 。HarmonyOS 5/6、真实平板、悬停和硬件视频仍待验收。

工程与资料
在“工程包”中新建工程，填写名称、线路、类别、地址和备注。点工程卡片选择当前工程，“当前”会紧邻标题显示。搜索名称或线路，按日期或名称排序；批量操作支持分类、归档、锁定和导出。
锁定仅禁止该工程继续拍照和录像，既有资料仍可编辑、移动、删除和导出。

拍照与录像
先选工程，再进入“拍摄”。相机权限必需；定位和麦克风可选。拒绝定位仍可拍摄，拒绝麦克风可录制无声视频。没有闪光灯、镜头或录像能力时，相应控件不可用。
取景页可选择拍摄方向。快门时冻结时间、工程信息、定位和水印设置。旧定位会注明状态，地址解析失败不影响拍摄。
照片四档画质分别为长边 1280、1920、2560 和原尺寸，JPEG 质量 65、75、85 和 95。
录像结束后处理水印，处理期间可查看进度或取消。处理失败会保留原片并显示待处理状态，在相册详情中重试。进入后台会结束录制或取消处理，不保证后台持续转码。

水印与模板
从相机的水印入口或设置中的“自定义水印字段与样式”进入同一面板。八款样式按面板宽度显示一到四列。切换样式保留字段、字号、透明度和位置；“使用此样式”才会改变拍摄配置，“取消”保持原配置。
支持自定义字段及命名模板。另存模板会保存草稿，不会自动应用到拍摄。

相册、问题和编辑
相册可按工程、日期、类别、问题等级和处理状态筛选。勾选资料后可移动、分享、删除或导出。
照片支持缩放查看；在详情中填写问题名称、说明、等级和处理状态。
编辑支持旋转、水平或垂直翻转、裁剪、箭头、文字和马赛克。选择工具后在照片上拖动；文字需要先填写内容。支持撤销和重做。
保存编辑成品不会覆盖工程原图，详情可切换查看。

导出与系统相册
工程导出可选择 ZIP 或总文件夹。文件夹通过系统授权保存到下载目录。导出包含工程信息、照片、视频、独立编辑成品、CSV 清单和结果报告。缺失文件会列入报告，不会假报全部成功。
“拍摄后保存副本到系统相册”会请求系统授权；取消不影响应用内原件。系统相册副本与工程原件是独立文件，两处独立删除。已存在资料可在详情中另存副本。
卸载或换机前请先导出资料。本版不支持导入 Android 工程包，也不提供账号和云同步。

设备与显示
界面按窗口宽度调整：手机单列，中等窗口增加列数，大窗口展示列表和详情双栏。旋转、折叠和分屏时保留当前工程、筛选和编辑草稿。
桌面默认 D“工程现场”图标；支持 API 26 的系统可在设置中切换 A/B/C/D。旧系统固定 D。

使用帮助
教程离线可读，设置中可重看首次指引。定位不可用时检查系统开关和权限；无声录像需要在下一次录制前补开麦克风权限。
此开发版本尚需鸿蒙真机验证相机、定位和视频编解码。模拟器能力不足时会明确提示，不能以模拟器结果代替真实成片验收。

折叠屏与大屏
按实际窗口宽度调整布局：小于 600 vp 为手机单栏；600–839 vp 增加列表列数；840 vp 起工程、相册使用列表与详情双栏，编辑工具位于图片右侧。旋转后保留当前资料和多选。侧边水印字段可上下滚动。模拟器缺少有效折痕区域时保持普通响应式布局，真实悬停仍待验证。
