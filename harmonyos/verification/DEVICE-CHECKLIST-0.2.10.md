# SiteCam 鸿蒙 0.2.10 实机检查清单

> 历史批次记录；最新统一规则及交付版本为 0.3.0，见 harmonyos/SCREEN-ADAPTATION.md 与 verification/REVIEW-0.3.0.md。
当前交付：0.2.10 / versionCode 12 / com.sitecam.app / arm64-v8a。最低配置 HarmonyOS 5.0.0（API 12）；编译与目标 API 26。以下未勾选项须在真实设备完成，模拟器结果不能替代。

## 安装准备

- [ ] 记录机型、系统版本与 API，确认设备支持原生 HarmonyOS HAP。
- [ ] 用户在 DevEco 登录开发者账号，连接设备并授权调试，在工程签名设置中完成设备对应的签名配置。账号、验证码和签名私钥不写入仓库或检查记录。
- [ ] 使用本轮源码生成签名 HAP 并安装。dist/debug 与 dist/release 中现有 HAP 均未签名，不能直接作为普通真机安装包。
- [ ] 启动后确认 0.2.10（12）。已有同签名旧版时直接覆盖，核对工程、媒体、问题、模板和当前选择保留；没有旧版时标记“覆盖升级未测”，不要为测试卸载用户应用。

构建入口：harmonyos/scripts/build.sh。脚本默认在 ~/Library/Caches/SiteCamHarmonyBuild 构建中文路径工程的镜像，源码修改应在 harmonyos 完成。个人签名需在 DevEco 配置后生成，不向 build-profile.json5 提交个人凭据。

## 拍摄与水印

- [ ] 相机授权后能预览拍照；拒绝定位仍可保存，拒绝麦克风时可录无声视频。运行中撤销权限后提示清楚，补开权限能恢复。
- [ ] 竖屏、左横屏、右横屏各拍一张，对照取景、成片方向和比例；无重复旋转或黑边。
- [ ] 变焦、点击对焦、镜头切换与可用闪光模式正常；不支持的能力不误报可用。
- [ ] 将工程标签改为“今日水印”，增加带内容的自定义字段并移到第一。八款样式逐一核对预览与成片，长标签、多行地址不裁切、不遮挡。
- [ ] 设置页只编辑标签；拍摄页修改内容。返回、重启后标签、顺序、内容保留。
- [ ] 恢复默认仅改变当前模板系统标签与顺序，内容、自定义字段、开关及样式保留；既有照片不重画。
- [ ] 连续拍摄以及拍摄中切换窗口后无重复、丢失或错归工程；定位时间、经纬度及照片 EXIF 正确。

## 视频优先验收

- [ ] 录制带声音的短视频，验证原生水印输出能完成并播放；核对首、中、尾帧水印、方向、时长和音画同步。
- [ ] 录制无声视频及左右横屏视频，确认音轨与方向正确。
- [ ] 长视频、取消处理、切后台与中断后保留原片，显示失败/待重试状态，重试可成功。
- [ ] 相机占用或编解码失败后仍能返回拍照；失败不得标记为 READY。

模拟器当前没有可用 H.264 编解码器，以上视频成功路径均未验收。需以真实输出判断，不能仅凭 Native 编译通过勾选。

## 整理、导出与设备布局

- [ ] 编辑旋转、裁剪、箭头/文字/马赛克后另存成品，原件独立保留，撤销重做顺序正确。
- [ ] 系统相册授权取消后工程原件可读；允许后产生独立副本。分别删除副本和工程资料，验证互不联动。
- [ ] 导出 ZIP 和目录，实际打开照片、视频、编辑成品、CSV 与报告；缺失或交付失败如实列出。系统分享需由用户选择接收应用，不自动发送。
- [ ] 手机普通字体一屏至少四张完整工程卡，编辑、导出常驻；大字体不截断关键操作。
- [ ] 折叠开合、旋转、平板和分屏后当前工程、筛选、多选及详情保留；宽屏双栏可操作。
- [ ] 在 HarmonyOS 5/6 目标设备复核拍照、定位、编辑、导出和图标兼容；旧系统保持固定 D 图标。

## 判定与记录

每项记录通过/失败/未测、设备及复现步骤。出现资料丢失、核心流程崩溃、视频输出错误或升级破坏数据时先修复，不作为验收通过。实拍资料保留本地；本轮无 GitHub、官网和应用市场发布。

## 折叠内屏平行视界与握持检查

- [ ] 普通直屏手机及折叠外屏：相册仍为单页，横屏不触发内屏分栏。
- [ ] 两折/三折展开内屏：左列表、右照片预览，当前照片高亮，编辑/分享/另存入口可用。
- [ ] 原图/编辑成品选择及缩放在折叠、展开、左右旋转后保留；切换照片后缩放正常复位。
- [ ] 筛选列表不自动替换右侧照片；删除预览照片后不再显示已删除文件。
- [ ] 大屏横拍相册、快门、镜头切换集中在右侧，左右握持触达舒适，无误触；近方形竖拍保持原有上下布局。
