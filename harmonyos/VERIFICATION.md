## 当前最实质的三个功能缺口

1. **视频水印输出仍无法验收**：测试模拟器没有可用 H.264 编解码器，`harmonyos/entry/src/main/ets/core/VideoService.ets` 依赖原生编码路径，33 项测试仍为 32 项通过、视频项失败。
2. **真实设备与旧系统兼容性尚未实测**：目前只有 API 26 模拟器证据，`harmonyos/entry/src/main/ets/core/CameraService.ets`、`LocationService.ets` 和 `VideoService.ets` 的真机相机、定位、录像组合仍未在 API 12/HarmonyOS 5/6 或鸿蒙真机验证。
3. **最终全量 UI 矩阵仍未完成**：工程批量分类、移动资料、导出入口及宽屏详情已有专项结果，但不同窗口、字体、折叠姿态、混合媒体和系统文件管理器的完整组合仍需一次最终回归。

首次使用测试模拟器时遇到的输入法服务条款未代为接受；布局使用专用模拟器的虚构工程资料。测试种子数据不打包进正式应用，也未导入或覆盖用户原有 Android 资料。

没有市场发布、账号、云同步、Android 工程包导入、电脑/穿戴版本，也没有为视频失败提供假完成回退。
